## Why
Users need a dark mode option to reduce eye strain during nighttime usage and improve accessibility for users with visual sensitivities.

## What Changes
- Add dark/light theme toggle in user settings
- Implement theme persistence across sessions
- Update UI components to support both themes
- **BREAKING**: Theme system will affect all UI components

## Impact
- Affected specs: ui/theme, user-preferences
- Affected code: All UI components, layout components, theme system
