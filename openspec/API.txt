# API

这是关于微喇 api 的文档说明

## 示例

http://localhost:8090/v2/corp/auth/login?appid=102036&et=1741491127&sign=e056a1e5
{
	"email": "weila@qq.com",
	"verifycode": "412604",
	"password": "e10adc3949ba59abbe56e057f20f883e"
}
{
	"errcode": 0,
	"errmsg": "请求成功",
	"data": {
		"country_code": "0",
		"password": "85afb53b4f60110b3eac365e5cd76d75",
		"user_number": "70012122"
	}
}

### 分类

这段示例内容有三个部分: 

1. 请求 url (必有)
2. 请求参数 (可无)
3. 返回内容 (可无)

你需要自行判断是内容有哪几部分

### 使用

1. url: 文档提供的 url 为完整 url，在实际使用中需要将 baseURL 和 query 参数去掉 -> corp/auth/login
2. 请求参数：正常传递
3. 返回内容：由于我们用到了响应拦截器。我们收到的数据会不同，请根据不同情况生成合理的return type interface

返回内容情况一：

{
	"errcode": 0,
	"errmsg": "请求成功",
	"data": {
		"user": {
			"name": "Alex",
			"age": 18
		}
	}
}

由于 data 中只有一个 user 字段，我们将得到 user 字段的值

返回内容情况二：

{
	"errcode": 0,
	"errmsg": "请求成功",
	"data": {
		"users": [
			{
				"name": "Alex",
				"age": 18
			},
			{
				"name": "Jack",
				"age": 20
			}
		],
		"count": 2
	}
}

由于 data 返回的对象有两个及以上的字段，我们将得到 data 字段的值
