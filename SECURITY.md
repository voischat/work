# Security

This repository is public for viewing and evaluation. It is not an offer of
support, and external contributions are not accepted.

## Reporting a vulnerability

Report security issues through the repository's **Security** tab with GitHub
private vulnerability reporting. Do not open a public issue for a
vulnerability.

Include the affected route, file, or dependency, the steps that reproduce the
issue, and the impact you observed. We acknowledge reports on a best-effort
basis and will not take action against researchers who report in good faith.
