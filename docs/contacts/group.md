# 群组管理

群组管理用于管理企业的对讲群组，支持创建、编辑和解散群组。

![群组管理](../assets/group-management.png)

## 创建群组

1. 点击"创建群组"按钮
2. 填写群组名称、选择对讲模式、所属部门等
3. 添加群组成员
4. 提交完成创建

## 群组操作

- 在群组列表中可查看群组头像、名称、用户数量、对讲模式、部门及创建日期
- 支持编辑群组信息和删除群组

## 发送消息

可以通过以下两种方式给群组发送消息，发送后会跳转至工作台会话并打开对应的群组聊天：

1. 在群组列表中，点击行末"操作"列的下拉箭头，选择"发送消息"。

   ![群组列表发送消息](../assets/group-send-message.png)

2. 进入群组详情页面，点击右上角的"发送消息"按钮。

   ![群组详情发送消息](../assets/group-detail-send-message.png)
