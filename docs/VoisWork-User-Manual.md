# VoisWork User Manual

## 1. Account Management

### 1.1. Register Account (https://www.voiswork.cn/#/register)

**Step-by-Step Instructions:**

1. **Access Registration Page**
   - Click the "Register" button on the login page to enter the registration page

2. **Fill in Registration Information**
   - Enter email address
   - Enter graphic verification code
   - Get and enter email verification code
   - Set login password
   - Read and agree to the privacy agreement

3. **Complete Registration**
   - Click the "Register" button to submit information
   - After successful registration, automatically redirect to the login page

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.21.26%20PM.png)

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.22.55%20PM.png)

**Notes:**

- Email address must be valid
- Password must meet security requirements
- Must agree to the privacy agreement to register

### 1.2. Account/Email Login (https://www.voiswork.cn/#/login)

**Login Methods:**

#### Method 1: Password Login
1. Enter account/email
2. Enter password
3. Optionally select "Remember Password" feature
4. Click the "Login" button

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.23.49%20PM.png)

#### Method 2: Email Verification Code Login
1. Switch to "Email Login" tab
2. Enter email address
3. Enter graphic verification code
4. Get email verification code
5. Enter the received email verification code
6. Click the "Login" button

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.24.31%20PM.png)

**Features**

- Supports both account password and email verification code login methods
- Remember password feature for quick next-time login
- Click "Forgot Password" link to reset when password is forgotten

## 2. Enterprise Information (https://www.voiswork.cn/#/contact/org)

### 2.1 Enterprise Basic Information

Enterprise basic information includes:
- **Enterprise Name**: Displays the full name of the enterprise
- **Enterprise Avatar**: Enterprise identification image
- **Verification Status**: Displays enterprise verification status
- **VIP Information**: Displays membership level and validity period
- **Statistics**:
  - Number of members
  - Number of departments
  - Number of groups
  - Number of devices

### 2.2 Enterprise Verification

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.27.40%20PM.png)

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.31.01%20PM.png)

**Verification Process:**

#### Step 1: Fill in Verification Information

**Enterprise verification requires:**

- Enterprise name
- Unified social credit code (18 digits)
- Business license photo

#### Step 2: Submit for Review

- Wait for platform review after submitting verification information
- Review status includes: Pending review, Approved, Rejected
- Specific reasons will be displayed when review fails

**Verification Status Description:**

- **Pending Review**: Information submitted, waiting for platform review
- **Approved**: Verification successful, enterprise information verified
- **Rejected**: Verification failed, need to modify information and resubmit based on prompts

## 3. Contacts

### 3.1 Member Management (https://www.voiswork.cn/#/contact/member)

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.51.04%20PM.png)

#### Create New Member
![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.51.29%20PM.png)
**Operation Steps:**
1. Click the "Create Member" button on the member management page
2. Fill in member information:
   - **Name** (Required): Member's real name
   - **Department** (Optional): Select所属department
   - **Employee ID** (Optional): Employee number
   - **Email** (Optional): Contact information
   - **Password** (Required): Initial login password
   - **Gender** (Optional): Select gender
   - **Avatar** (Optional): Upload member avatar
   - **Location Sharing** (Optional): Enable location sharing
   - **Department Admin** (Optional): Set as department administrator
   - **Track Permission** (Optional): Set track viewing permission level

3. Click "Submit" to complete creation

#### Add New Device
![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%205.51.39%20PM.png)
**Operation Steps:**
1. Click the "Add Device" button
2. Fill in device information
3. Complete device addition

## 4. Workbench

### 4.1 View Member Track (https://www.voiswork.cn/#/workbench/user-track)

**Operation Steps:**

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%206.15.00%20PM.png)

![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%206.15.19%20PM.png)
![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%206.15.38%20PM.png)
![](./assets/intl-manual-screenshot/Screenshot%202026-01-29%20at%206.15.57%20PM.png)
#### Step 1: Select Member
1. Enter Workbench -> User Track page
2. Select target member from the department tree on the left
   - Expand department tree to view all departments
   - Click department to load member list under that department
   - Select specific member

#### Step 2: Select Date
1. Use date picker to select the date to view
2. System will automatically load track data for that date

#### Step 3: View Track
1. **Map View**:
   - Display member's movement track line on the map
   - Track points displayed as markers
   - Click marker to view detailed information of that location

2. **Track List**:
   - Click menu button in upper right corner of map to open track list
   - Display time, latitude and longitude information of all track points
   - Click "View" button to locate to specific position

3. **Location Details**:
   - Click marker point on map
   - Display detailed location information:
     - Province, city, district, street detailed address
     - Specific time
     - Latitude and longitude coordinates

**Features:**
- Supports querying historical tracks by date
- Map visualization of movement path
- Detailed location reverse geocoding information
- Track point timeline display
- Quick positioning to specific location
