# Contributing

This repository is a public read-only view of a company product. External
contributions are not accepted.

- Pull requests from outside the organization are closed without review.
- Issues from outside the organization are for bug reports about the published
  product; use the product support channels for account or billing questions.
- Security reports go through [SECURITY.md](./SECURITY.md), never a public
  issue.

Internal contributors follow the repository guides: [AGENTS.md](./AGENTS.md),
`packages/core/AGENTS.md` and `apps/website/AGENTS.md`.
